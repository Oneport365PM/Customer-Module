Tasks are built from four modules

Every job gets the Core tasks, plus the tasks for each service it includes.

Core

Done on every job: build the shipment, assign the file, invoicing, filing, closure and SLA review.

OF / AF

Freight: booking with the line or airline, ERO, SI, draft BL or AWB, vessel or flight tracking, carrier invoices, OBL.

H

Haulage: vendor and truck allocation, empty pick-up, gate-in, delivery, EIR, waybill and empty return.

CBT

Customs clearing and documentation: NXP, NESS and CCI, Form M and PAAR, assessment, duty, release, FECD.

OneExport Haulage = Core + HOneImport H + CBT = Core + H + CBTVAAS AF + CBT = Core + AF + CBTFreightSaver = Core + OFAuto Import = Core + OF + vehicle documents

SLAs

How time is counted
Hours

An SLA in hours (h) means clock hours, 24 a day. Only where the SOP says working hours is time counted 8:00–17:00 WAT, Monday to Saturday.

Days

An SLA in days means calendar days. Only where the SOP says working days is time counted Monday to Saturday.

Working time

8:00–17:00 WAT, Monday to Saturday. Public holidays count as working days; the clock does not pause.

End-to-end

Every end-to-end SLA is measured in calendar days.

Range

A range such as 24–48 h or 10–14 days is on track up to its upper figure and breached after it.
